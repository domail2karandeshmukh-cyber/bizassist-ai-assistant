# BizAssist AI Assistant

BizAssist AI Assistant is a prototype created for the project "AI Assistant for SMEs".

## Project Objective

The objective of this project is to help Small and Medium-sized Enterprises generate draft quotations from client requests using an AI-style assistant.

## Features

- Client request input
- Draft quotation generation
- Pricing summary
- Terms and conditions
- Email reply draft
- Copy quotation option

## Technology Used

- HTML
- CSS
- JavaScript
- GitHub
- Vercel for deployment

## Important Note

This version uses simulated AI output for academic demonstration. In a production version, the system can be connected to a real AI model through a secure backend API.
